> Current tester release candidate. X04G only.

For vulnerabilities involving OTA, signatures, AVB, ADB/root, MQTT, WebView or the installer, contact the repository maintainer privately. Include X04G model, RC versions, observed impact, minimal reproduction without personal data, redacted logs and a proposed mitigation if available.

Do not publish keys, tokens, credentials, backups, full ADB logs, personal identifiers or exploitation details in public issues. Wait for a fix or explicit agreement before technical disclosure.
