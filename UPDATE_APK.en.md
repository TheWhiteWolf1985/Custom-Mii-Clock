> Installer 1.5.2 · firmware 0.1.20 (032) · launcher 0.26.5 / versionCode 58

> Current tester release candidate. X04G only.

Release `launcher-v0.26.5` is a tester prerelease, package `local.miiclock.launcher`, versionCode 58. It is not automatically offered by the `releases/latest` check. APK, signed manifest, signature and checksums must come from the same release.

The signed OTA range is firmware 027–032; native bootstrap/HOME changes require firmware 032. An APK update does not write firmware partitions or require a reset. If 032 already contains 0.26.5/58, the app is already current.

First migration from a legacy watchdog and its recovery remain physically unqualified.
