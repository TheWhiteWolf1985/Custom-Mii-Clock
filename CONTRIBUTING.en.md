# Contributing to the RC

[Italiano](CONTRIBUTING.md) · **English**

> Installer 1.5.2 · firmware 0.1.20 (032) · launcher 0.26.5 / versionCode 58
>
> Current tester release candidate. X04G only.

Keep contributions focused and reproducible, compatible with Android 10, an 800 × 480 display and limited RAM. Open an issue before changes to firmware, OTA, security, MQTT, Assistant or privileges.

Preserve identity, backup, signature, AVB, consent and recovery checks; accompany logic changes with appropriate tests and update both documentation languages. Keep IT/EN/FR/DE/ES UI catalogues complete and assess memory/CPU before adding dependencies.

Do not add stock/personal dumps, unauthorized proprietary components, private keys or credentials. Binary changes require new validation and a consistent release. [Architecture, distribution and licensing](Documentazione/en/13-Development-Licenses.md).
