# Installazione firmware X04G

**Italiano** · [English](INSTALL_X04G.en.md)

> Installer 1.5.2 · firmware 0.1.20 (032) · launcher 0.26.5 / versionCode 58
>
> Release candidate corrente per tester. Solo X04G.

Usare MiiClock Installer 1.5.2 su PC Linux fisico compatibile per installare firmware 0.1.20 (032) con launcher 0.26.5/58. La procedura è limitata a X04G / `mico_x04g`.

1. [Leggere i requisiti e installare il DEB](Documentazione/it/07-Linux-Requirements.md).
2. [Verificare gli asset](Documentazione/it/12-Verification.md).
3. [Seguire tutti i passaggi della guida completa](Documentazione/it/08-Installation.md): controllo identità, backup personale, sblocco verificato, firmware firmato, sette scritture e reset manuale dopo il flash completo.
4. Completare provisioning Google/Home e controllo 4.7, poi provare le funzioni sul proprio Clock.

Il reset cancella i dati. Non anticiparlo al flash e non seguire indicazioni incompatibili del README di preparazione nello ZIP firmato. Non improvvisare comandi Fastboot/erase o usare il backup di un altro dispositivo.

In caso di errore seguire [Recupero](Documentazione/it/09-Recovery.md). L'aggiornamento del [solo APK](Documentazione/it/10-APK-Updates.md) è un percorso distinto, senza questo reset.
