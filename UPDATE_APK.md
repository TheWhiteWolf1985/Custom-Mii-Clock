# Aggiornamento APK 0.26.5

**Italiano** · [English](UPDATE_APK.en.md)

> Installer 1.5.2 · firmware 0.1.20 (032) · launcher 0.26.5 / versionCode 58
>
> Release candidate corrente per tester. Solo X04G.

La release `launcher-v0.26.5` è una prerelease per tester, package `local.miiclock.launcher`, versionCode 58. Non è proposta automaticamente dal controllo `releases/latest`. APK, manifest firmato, firma e checksum devono provenire dalla stessa release.

Il range OTA firmato è firmware 027–032; le modifiche native bootstrap/HOME richiedono firmware 032. Un update APK non scrive partizioni firmware e non richiede reset. Se 032 contiene già 0.26.5/58, l'app è già alla versione corrente.

La prima migrazione da watchdog legacy e il suo recupero restano da qualificare fisicamente.
