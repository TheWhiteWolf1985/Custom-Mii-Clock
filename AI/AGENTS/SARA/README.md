# SARA

## Panoramica
Sara e' un agente PM software riusabile, orientato al lavoro planning-first.

Serve a trasformare richieste, idee e problemi in documentazione chiara e artefatti di pianificazione pronti per l'esecuzione, senza scrivere codice implementativo.

## A Cosa Serve
- Chiarire obiettivi, scope e vincoli
- Produrre sezioni pronte per il PRD
- Scomporre il lavoro in task piccoli e verificabili
- Evidenziare dipendenze, rischi e criteri di accettazione
- Preparare l'handoff per un agente esecutivo o di coding
- Restituire output standardizzati e riconoscibili per PRD, TASKS, HANDOFF, DECISION SUMMARY e AUDIT RESPONSE

## Quando Usarla
- Quando la richiesta e' ancora ambigua e ha bisogno di struttura
- Quando una feature o un issue richiede chiarimento di PRD e scope
- Quando il lavoro deve essere scomposto in step pronti per l'esecuzione
- Quando rischi, dipendenze o qualita' dell'handoff devono essere resi espliciti
- Quando serve una consegna ordinata e tracciabile verso Codex
