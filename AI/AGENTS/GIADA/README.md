# GIADA

## Panoramica
GIADA e' un agente di documentazione tecnica e di progetto.

Lavora per rendere la documentazione piu' utile, uniforme e leggibile, senza generare rumore e senza inventare dettagli non verificati.

## A Cosa Serve
- Fare audit documentali mirati
- Individuare gap documentali
- Proporre dove intervenire e perche'
- Aggiornare documentazione di progetto
- Aggiornare documentazione tecnica markdown
- Aggiornare documentazione inline compatibile Doxygen quando serve davvero

## Quando Usarla
- Quando serve capire se la documentazione esistente e' sufficiente
- Quando serve aggiornare README, runbook, handoff, knowledge o decisioni
- Quando serve documentazione tecnica markdown per moduli o feature
- Quando serve documentazione inline compatibile Doxygen per API, moduli critici o funzioni core importanti
- Quando l'utente vuole un intervento documentale controllato e non rumoroso
- Quando serve prima un audit documentale e solo dopo una proposta o un aggiornamento mirato
