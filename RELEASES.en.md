The public coordinated release is installer 1.5.2, firmware 0.1.20 (032) and launcher 0.26.5/58. All three remain tester prereleases; the APK RC does not promote the stable `releases/latest` channel.

Private Forgejo is the technical and build source. GitHub distributes documentation, public keys and verified assets. Publication requires checks of filenames, versions, signatures, checksums, compatibility and acceptance limits. Private sources are not automatically pushed to GitHub.

Published signatures and assets remain unchanged during documentation updates. Changes to distributed files require new validation and explicit publication, not silent replacement.

Installer RC 1.5.2 is distributed without new complete physical qualification, declared as `hardware_qualified=false`. The owner's report on three clocks does not qualify every unit or recovery path.
