# MiiClock for Xiaomi Mi Smart Clock X04G

[Italiano](README.md) · **English**

> Installer 1.5.2 · firmware 0.1.20 (032) · launcher 0.26.5 / versionCode 58
>
> Current tester release candidate. X04G only.

MiiClock is firmware derived from X04G stock software with a launcher for clock, local alarms, weather, read-only calendar, persistent Home Assistant dashboard, MQTT, MediaSession controls and the Assistant visual overlay MiiPulse. **X04G / `mico_x04g` only**.

The owner reports that it works on three personal clocks. Distribution remains an **experimental tester RC**, with complete physical qualification of installer 1.5.2 and recovery still pending. [Versions, evidence and limitations](Documentazione/en/01-Release.md).
